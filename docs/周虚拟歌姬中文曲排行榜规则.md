# 周虚拟歌姬中文曲排行榜 — 完整规则

> 数据依据：哔哩哔哩（www.bilibili.com）站内数据
>
> 本项目实现为**日榜 / 周榜 / 月榜 / 年榜**四类周期，统计时段统一为周期起始日 **01:00**：
> - 日榜：每日 01:00 ～ 次日 01:00
> - 周榜：每周一 01:00 ～ 下周一 01:00
> - 月榜：每月 1 日 01:00 ～ 下月 1 日 01:00
> - 年榜：每年 1 月 1 日 01:00 ～ 次年 1 月 1 日 01:00

## 一、数据依据 & 收录范围

### 投稿版面：VOCALOID · UTAU

- 仅收录标题或简介处标注「引擎」和「虚拟歌手」名称的乐曲稿件
- 仅收录稿件实际音乐内容时长 **≥ 120 秒**的稿件，未达到的不予收录
- 以生成式模型产出音频或歌词的稿件，不予收录
- 仅收录可在站内公开观看且未进行替换的稿件（充电稿件、隐藏稿件、大量替换稿件不予收录）
- 非 VOCALOID · UTAU 分区的虚拟歌手稿件，仅二次补录可寻迹的「原创音乐」分区稿件，其余不予收录
- 除「虚拟歌手」名称能明确单一引擎归属外，应在视频标题或稿件介绍中任一处注明引擎名称；不标注而无法确认是否符合虚拟歌手定义的稿件不予收录

### 使用「歌声合成软件」制作的「现代汉语」为主要内容的「虚拟歌手」单曲

- 没有使用「歌声合成」技术的「虚拟歌手」作品不予收录，使用换声/混声技术的稿件一律视为人声
- 不得有明显人声参与并成为主角
- 「虚拟歌手」意指正式发行的「歌声合成软件」中，使用的独立声音资料库，且「虚拟歌手」声库须明确指向「非自然人形象」，不与自然人在运营形象上有同质关联
- 正常情况下，当「虚拟歌手」声库通过官方渠道发布试听曲目后，此时该声库纳入可收录范围。民间自制「虚拟歌手」以声库制作人发布可收录原创曲目，并配布该歌手获取方式后，该声库此时起纳入可收录范围
- 另外，若已纳入收录的「虚拟歌手」声库发布了迭代版本、更替合成引擎、更换展示形象等情况时，将视为相同「虚拟歌手」序列，不再视为不同「虚拟歌手」。全新「虚拟歌手」声库发布时间之前的作品，将不纳入收录范围
- 不可公开获取或有知识产权争议的「虚拟歌手」声库，一般不予收录

> [1] 官方渠道意指通过厂牌官网或认证可信的平台渠道
> [2] 使用多种声库/声源计算合成的混合「虚拟歌手」不视为可配布使用的「虚拟歌手」声库，故不纳入收录范围

### 以下情况可能不予收录

- 稿件整体无法成曲：包含多个曲目、无伴奏清唱、明显无调教、歌词基本无意义、含有大量破坏性失真/爆音的稿件
- 稿件信息模糊：稿件未在文本区域中标注作品或作者信息、搬运曲目无来源且未标注作者信息
- 稿件存在争议内容：存在严重套用参数、生成式模型参与创作的稿件、声库存在争议的
- 稿件中含有非作品本身的干扰因素：人身攻击、政史社评、修改原作品歌词
- 外文曲的直译稿件
- 线下首发歌曲的非纯净音频稿件
- 以商业广告为主要内容的稿件
- 以及其它不宜采收的稿件

### 同作者同曲多次投稿规则

- 在一个年度结算周期内只收录其中一个
- 同曲重置稿件须原稿件收录在「洛天依藏曲阁」中满一个年度结算周期后，可再收录一次，以此类推
- 制作人员相同的稿件，均视为同作者发布
- 若有完整版、PV版、二次重置等计划，发布时请注明【非最终版】
- 一个年度结算周期指「周刊虚拟歌姬中文曲排行榜」企划 · 年榜系列的收录截止时间

## 三、评分公式

统计范围内所有收录投稿的数据，按以下方式计算得点，按得点从高至低排名。

### 基本公式

```
最终得点 = 播放得点 + 互动得点 + 收藏得点 + 硬币得点 + 点赞得点
```

### 播放得点

```
播放得点 = 基础播放得点 × 修正D
若 播放 > 10000  →  基础播放得点 = 播放 × 0.5 + 5000
若 播放 ≤ 10000  →  基础播放得点 = 播放
```

### 互动得点

```
互动得点 = (评论 + 弹幕) × 修正A × 15
```

### 收藏得点

```
收藏得点 = 收藏 × 修正B
```

### 硬币得点

```
硬币得点 = 硬币 × 修正C
```

### 点赞得点

```
若 点赞 > 硬币 × 2  →  点赞得点 = 硬币 × 2
若 点赞 ≤ 硬币 × 2  →  点赞得点 = 点赞
```

> 1. 所有数据仅计算站内数据
> 2. 修正值保留小数点后两位

### 修正系数

#### 修正A（无上限）

```
((基础播放得点 + 收藏) ÷ (基础播放得点 + 收藏 + (弹幕 + 评论) × 20))²
```

#### 修正B（最大值：50）

```
若 收藏 > 硬币 × 2  →  修正B = (硬币² ÷ (播放 × 收藏)) × 1000
若 收藏 ≤ 硬币 × 2  →  修正B = (收藏 ÷ 播放) × 250
```

#### 修正C（最大值：50）

```
若 硬币 > 收藏  →  修正C = (收藏² ÷ (播放 × 硬币)) × 250
若 硬币 ≤ 收藏  →  修正C = (硬币 ÷ 播放) × 250
```

#### 修正D（最大值：1）

```
若 收藏 > 硬币  →  修正D = (硬币 ÷ 播放) × 25
若 收藏 ≤ 硬币  →  修正D = (收藏 ÷ 播放) × 25
```

## 四、永久成就标签

在本期达成下列成就的作品，在**下期及以后**的榜单展示中，会额外展示永久成就标签：

| 成就 | 条件 |
|------|------|
| **SUPERHIT（SH）** | 累计 **2 次**登上主榜前 3 名 |
| 年榜首位 | 首次成为年榜首位 |
| 门番达成 | 28 期内 20 次 **或** 50 期内 30 次登上主榜，且没有连续 8 期未上榜 |
| 神话达成 | 播放总量突破 **一千万** |

### SUPERHIT（SH）判定规则

- **首次达成**：一首歌在周刊主榜历史上累计进入前 3 名达到 **2 次**，即达成 SH
- 达成后，在后续所有期数的榜单展示中永久显示「SUPERHIT」标签
- 判定基于历史全量榜单数据，不限于当前年度

## 五、B站平台版面变更（灰度期调整）

由于 Bilibili 平台版面变更功能灰度上线，在平台方灰度测试周期，周刊将对收录范围进行以下调整。

对未在 VOCALOID · UTAU 区的投稿需满足以下要求：

### 1. 投稿标签满足下列要求之一

- **A.** 包含以下引擎标签：VOCALOID、Synthesizer V、ACE Studio、UTAU、DiffSinger、X Studio、DeepVocal、SharpKey、VoiSona
- **B.** 包含「虚拟歌手中文曲」标签
- **C.** 包含最近一期周刊歌手排名前十名的歌手名

### 2. 投稿分区选择「音乐」分区

> [1] 平台的灰度测试投稿系统的「分区」选项与原有分区定义不同，暂时不作为硬性条件，但与虚拟歌手创作过程无关的分区（如：「汽车」、「美妆cos」等）仍在收录范围外
> [2] 平台对于部分题材、内容和主题的稿件，因多方面原因会出现「锁藏」和「延迟展示」等情况，此类稿件通常存在 12 小时甚至永久的流量限制，期间除 BV 号以外无法用其他方式找到该稿件。延迟展示的曲目若在本期计分时间后恢复展示，本周五 22:00 之后的投稿在下期作为新曲收入，其余曲目在恢复后的下下期补录（上期排名显示为「榜外」）
